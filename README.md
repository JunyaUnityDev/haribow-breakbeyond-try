# BREAK BEYOND — 試遊版

HARIBOW 初単独公演（2026/9/29 めぐろパーシモン大ホール）の
**客席参加コーナー**を、ひとりで通して遊べるようにしたもの。

本番は紗幕に投影して、客席の人がコントローラーで操作する。
ここでは**キーボードだけ**で同じものが動く。

## 遊び方

| キー | |
|---|---|
| **スペース** | はじめる／打つ／次へ進む |
| **← →** | 動かす |

スペースを押すと進む。あとは ← → とスペースだけ。

## 中身

1. フリッキー（案内役）の導入
2. **ブロック崩し** — ロゴを壊してコアを狙う
3. **GATE** — 落ちてくるバーの隙間を、あなたが決める

音が出ます。
